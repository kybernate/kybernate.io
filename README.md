# Kybernate

The static coming-soon page for Kybernate, a project by CloudCourse GmbH.

## GitHub Pages

1. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
2. Confirm `kybernate.io` as the **Custom domain**. The `CNAME` file stores the same domain for branch-based publishing.
3. Point the apex domain to GitHub Pages at the DNS provider. Set `www` to `kybernate.github.io` if you also want the `www` address.
4. Select **Enforce HTTPS** after GitHub validates the DNS records.

[Custom domain and DNS setup](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
